# bencho-alt

A small, free alternative to [Bencho](https://bencho.dev): interactive React blocks with motion, gestures and UI sounds.

## Stack (all MIT, free)

| Package | Role |
| --- | --- |
| `motion` | Animation and springs |
| `@use-gesture/react` | Swipe gestures |
| `use-sound` (uses `howler`) | Interface sounds |
| `tailwindcss` + `@tailwindcss/vite` | Styling |

## Blocks

Each block lives in `src/blocks/` and can be copied into another project on its own.

- `SlideToConfirm`: slide gesture, drag the knob to the end (tick and success sounds)
- `MagneticButton`: hover gesture, pulled toward the cursor (tick and pop sounds)
- `SwipeCards`: swipe gesture, flick cards off a deck (drop sound)

Sounds in `public/sounds/` are generated by `node scripts/make-sounds.mjs`, so there are no third-party audio licences to worry about.

## Run

```bash
npm install
npm run dev
```
